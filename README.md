## Project Description
This project focuses on learning how JavaScript interacts with HTML through the Document Object Model (DOM). I practiced selecting elements, navigating through the DOM, modifying content and styles, and creating and removing elements.

I also learned how to handle events, validate forms, and use event delegation. Finally, I applied these skills by building an interactive To-Do List application.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Git
- GitHub

## Features
- Selecting HTML elements using different DOM methods.
- Navigating through parent, child, and sibling elements.
- Modifying text, HTML content, attributes, and styles.
- Creating, cloning, and removing HTML elements.
- Handling mouse and keyboard events.
- Building an interactive click counter.
- Implementing keyboard shortcuts.
- Validating form inputs.
- Using event bubbling and event delegation.
- Adding new tasks to the To-Do List.
- Marking tasks as completed.
- Deleting tasks.
- Filtering tasks by All, Active, and Completed.
- Clearing completed tasks.
- Editing tasks.

## Lessons Learned
I learned how to use JavaScript to interact with HTML elements through the DOM. I practiced selecting elements, navigating between elements, changing content, modifying styles, and creating new elements dynamically.

I also improved my understanding of event listeners, form validation, event bubbling, and event delegation.

Building the To-Do List helped me understand how to use JavaScript functions and arrays to create interactive applications.

## Challenges Faced
One challenge I faced was understanding the different DOM selection methods and knowing when to use each one.

I also found event bubbling and event delegation challenging, especially when handling clicks on buttons inside list items.

Another challenge was managing tasks when adding, editing, completing, and deleting them. I solved these challenges by breaking the project into smaller functions and testing each feature individually.
